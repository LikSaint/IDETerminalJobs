# Job Bar

Плагин для WebStorm и других IDE на платформе IntelliJ: панель с часто используемыми командами проекта.

## Зачем

В проекте обычно набирается десяток команд, которые нужно запускать регулярно: поднять фронт, поднять мок API, освободить порт, подтянуть переводы для нужного модуля. Держать их в терминале, искать в истории shell или каждый раз заводить Run Configuration неудобно.

Job Bar собирает их в одну панель (tool window **Job Bar** внизу IDE). Каждая команда — это «джоба»: её можно запустить одной кнопкой, видеть статус, открыть вывод в консоли и перезапустить.

## Возможности

### Два режима запуска
- **One-shot command** — команда выполняется и завершается (`yarn lokaliser fetch …`, `lsof -ti:3001 | xargs kill`). Пока команда идёт, показывается лоадер. После завершения появляется зелёная (Success) или красная (Error) точка. Success показывается 5 секунд и гаснет, Error остаётся до следующего запуска.
- **Tracked process** — долгоживущий процесс (dev-сервер, watch-сборка, мок API). Плагин следит за его выводом и показывает текущее состояние: собирается, работает, есть ошибки. В строке есть кнопки Stop и Restart.

### Статус по выводу, а не только по exit code
Для каждой джобы задаются три набора паттернов, по одному на строку. Префикс `regex:` означает регулярное выражение; регистр и ANSI-цвета не учитываются:
- **Build / rebuild** — процесс начал пересборку, показывается лоадер;
- **Error** — в выводе ошибка;
- **Recovery** — процесс снова в рабочем состоянии.

Для one-shot это важно: многие утилиты (например, `yarn run`) печатают ошибку, но завершаются с кодом 0. Если последним в выводе совпал error-паттерн, джоба получит статус Error.

### Готовность по порту или URL
Для tracked-процесса можно указать порт (`4200`) или адрес (`http://localhost:4200`) на вкладке Status. Пока процесс стартует, плагин раз в секунду проверяет их, и как только порт открылся или адрес ответил, джоба становится готовой (зелёной). Работает вместе с recovery-паттернами и избавляет от подбора строк под каждый инструмент.

### Группы
⋮ → **Add Group**: группа запускает несколько джоб одной кнопкой.
- **One after another** — следующая джоба стартует, когда предыдущая готова (one-shot — завершилась успешно, tracked — стала зелёной). При первой ошибке запуск останавливается.
- **All at once** — все сразу.
- Для джоб с вариантами выбирается вариант или «All variants».
- Статус группы собирается из статусов участников, в подсказке — сколько готово (`2/3 ready`). **Stop** останавливает всех участников, **Open Console** открывает их вкладки в окне Run.
- Группа ведёт себя как обычная джоба: есть в списке, в тулбаре и в Keymap.

### Готовые пресеты
При выборе типа джобы паттерны подставляются автоматически. Есть пресеты для Angular, Vite, npm / Node.js, TypeScript compiler, Jest, Docker Compose и Spring Boot. Их можно поправить вручную или сбросить кнопкой **Reset to Type Preset**.

### Параметры и варианты
В команду можно вставить плейсхолдер, например `yarn lokaliser fetch affiliate_top ${file_name}`, и задать список вариантов (`common`, `home`, `auth`, …). При запуске открывается popup с поиском, где выбирается вариант. Если плейсхолдера в команде нет, значение дописывается в конец команды.

### Порядок и сортировка вариантов
- По умолчанию порядок вариантов ваш: строки можно двигать кнопками ↑ / ↓ под таблицей.
- Кнопка сортировки открывает список: Label A → Z / Z → A, Value A → Z / Z → A. После выбора строки сортируются один раз, дальше порядок снова можно менять вручную. Числа внутри строк сравниваются как числа (`item2` < `item10`).
- Галочка **Auto-sort** фиксирует выбранную сортировку: таблица пересортировывается после каждой правки, а кнопки ↑ / ↓ отключаются.

### «All» — прогон всех вариантов по очереди
На вкладке Parameters можно включить галочку **Add an “All” option** (только для one-shot). Тогда в popup появится пункт **All**:
- варианты запускаются по порядку;
- следующий стартует только после Success предыдущего;
- при первой ошибке прогон останавливается, а в консоли пишется, на каком варианте он упал и сколько вариантов пропущено;
- прогресс виден в подсказке у лоадера (`Running all · 3/25 · auth`), остановить прогон можно кнопкой Stop.

### Ярлыки джоб в тулбаре IDE (компактный вид)
Короткие цветные ярлыки всех джоб, в том же порядке, что и в списке.
- По умолчанию стоят в верхнем тулбаре IDE (New UI), слева от виджета запуска.
- Их можно поставить в любой тулбар: **Settings → Appearance & Behavior → Menus and Toolbars** (или ПКМ по тулбару → **Customize Toolbar…**) → добавить группу **Job Bar Jobs**.
- Текст ярлыка — **Short name** из настроек джобы (если пусто — имя). Можно задать **иконку**: тогда статус показывается яркой точкой в углу иконки, а с галочкой **Icon only** текст скрывается совсем. В наборе есть Angular, React, Vue, Node.js, npm, yarn, Docker, моки, переводы, API, сервер, деплой, git и иконки IDE; пункт **Custom file…** позволяет взять свой SVG или PNG (файл внутри проекта сохраняется относительно `$PROJECT_DIR$`). Цвет — статус: зелёный — работает / успешно, оранжевый — ошибки в выводе, красный — упала, серый — не запущена; во время выполнения рядом лоадер.
- Клик по ярлыку открывает меню с командами джобы; варианты параметров (и «All») — подменю у **Run**.
- Скрыть ярлыки во всех тулбарах: ⋮ панели Job Bar → **Show Job Labels in Toolbars**.

### Горячие клавиши
Каждая джоба — действие IDE **Run <имя джобы>**. Сочетание назначается в **Settings → Keymap → Plugins → Job Bar** (или поиском по имени джобы). Если у джобы есть варианты, по сочетанию открывается их список. Сочетание сохраняется при переименовании джобы.

### Консоли
- Джобы работают в фоне: вкладка с выводом тихо добавляется в стандартное окно **Run**, но само окно не открывается и текущая вкладка не переключается. На передний план её выводит только **Open Console** (в строке джобы или в меню ярлыка).
- У каждой джобы своя вкладка с её именем.
- Пути к файлам в выводе (`src/app/foo.component.ts:12:5`, `./src/main.ts(3,1)`, абсолютные пути) кликабельны и открывают файл на нужной строке. Относительные пути считаются от рабочей директории джобы.
- На вкладке есть кнопки **Rerun** (повторить последний запуск с тем же вариантом) и **Stop**, а также стандартные кнопки консоли (перенос строк, прокрутка, очистка).
- Если включено **Reuse console**, следующие запуски пишут в ту же вкладку, а перед каждым запуском печатается строка с временем и командой. Если выключено, каждый запуск заменяет вкладку новой.
- **Restart** повторяет последний запуск с тем же вариантом.

### Звуки
Короткие тихие сигналы: успешное завершение или готовность, ошибка, самостоятельное завершение tracked-процесса. Пересборки без ошибок, шаги прогона «All» и участники запускающейся группы молчат — звучит только итог. Отключаются через ⋮ → **Play Sounds**.

### Импорт из package.json
⋮ → **Add from package.json…** находит скрипты во всех `package.json` проекта (без `node_modules`), определяет пакетный менеджер по lock-файлу (`yarn` / `pnpm` / `bun` / `npm`) и создаёт из выбранных скриптов джобы. Режим (one-shot или tracked) и пресет паттернов подбираются по имени и тексту скрипта.

### Управление списком
- Добавление, редактирование, копирование, удаление джоб, перемещение вверх и вниз — через контекстное меню строки.
- **Enabled** (меню джобы или галочка в Edit Job): выключенная джоба остаётся в списке серой, но не запускается и пропадает из тулбаров и Keymap.
- Джобы хранятся отдельно для каждого проекта, в `.idea/jobBar.xml`.
- **Export / Import** (меню ⋮ панели) — сохранение всех джоб в XML и загрузка их обратно, например чтобы перенести набор в другой проект или поделиться с командой.

### Рабочая директория
В поле Working directory можно использовать `$PROJECT_DIR$` — корень текущего проекта. На macOS и Linux команды выполняются через `/bin/zsh -lc`, поэтому доступны `nvm`, `yarn` и прочее, что настроено в профиле shell. На Windows команды выполняются через `cmd.exe /c`.

## Установка

1. Соберите плагин (см. ниже) или возьмите готовый zip.
2. **Settings → Plugins → ⚙ → Install Plugin from Disk…** → выберите `build/distributions/JobBar-<версия>.zip`.
3. Перезапустите IDE. Панель **Job Bar** появится внизу; первая джоба создаётся через ⋮ → **Add Job**.

## Сборка

Нужен JDK 21. Подойдёт JBR из самой IDE: `/Applications/WebStorm.app/Contents/jbr/Contents/Home`. Также нужен Gradle 9.x: Gradle wrapper в репозитории пока нет.

```bash
JAVA_HOME=/Applications/WebStorm.app/Contents/jbr/Contents/Home \
  gradle buildPlugin -PlocalIdePath=/Applications/WebStorm.app/Contents
```

С `-PlocalIdePath` плагин собирается против установленной IDE. Без него Gradle скачает WebStorm 2025.3.1.1. Результат сборки: `build/distributions/JobBar-<версия>.zip`.

Поддерживаемые версии IDE: 2025.3 (build 253.*).
